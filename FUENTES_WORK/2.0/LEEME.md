# Cómo usar esta documentación

1. Abrí FUENTES_WORK: contiene los nueve archivos que reemplazan las fuentes anteriores del Proyecto.
2. Comprobá que las fuentes activas muestren “revisión 2.0”; evitá mantener también las anteriores.
3. DOCUMENTOS_CANONICOS contiene los 23 documentos completos para el repositorio cuando se autorice publicarlos. No hace falta cargarlos además como Fuentes.
4. La arquitectura se mantiene. Hay correcciones técnicas definidas y preguntas de funcionamiento pendientes, detalladas en 02_ARQUITECTURA_Y_DECISIONES.md, registro OPEN.
5. Esta entrega actualiza documentación: no contiene plugin, no modificó WordPress/Supabase/n8n/GitHub y no inicia implementación.

Pendientes principales: reglas de estados, campos/adjuntos/entregas, login y permisos, destinatarios de avisos. También deben fijarse parámetros de seguridad y verificar entornos/proveedor antes de sus fases. No se presentan esas decisiones como aprobadas.
